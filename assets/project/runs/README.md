# 实际运行产物

这里接收已获用户授权的外部训练/评估执行器输出。台账 new 只登记默认 run_dir，不创建或启动运行。目录存在、PID 文件或 status=running 都不能证明进程存活；需要现场核验并注明方式与时间。

默认使用 `<EXP-ID>-<slug>/`，也可通过 `set EXP-ID run_dir=真实路径` 登记其他位置。不要移动、覆盖或删除旧产物以适应新目录。配置快照属于 experiments/ 下配套目录，不是训练输出。

每次真实运行保留命令、协议、日志、指标和所用代码/数据/权重来源，按需要登记 hash；避免把大文件复制到索引。敏感信息及数据许可按实际项目边界处理。初始化尚无运行产物。
