# 科研解释与评审

这里按需保存对实际实验或论文主张的深入人工分析，不是自动生成的成功结论。初始化尚无评审记录。

独立分析应说明对象与日期、相关组和 EXP、实际观察与证据路径、竞争解释、适用边界、判断和未闭环问题。必要时从 EXP 或组 README 链接；重要判断变化追加 CHANGELOG，当前选择维护在 CURRENT。不要创建与台账竞争的执行状态表。

review_status=pending 表示人工解释待闭环，不是实验失败。确认解释闭环后可设为 done；执行状态 done 不自动完成解释，也不清除后续任务。具体任务、完成项和边界分别写入 next、next_done、constraint。
